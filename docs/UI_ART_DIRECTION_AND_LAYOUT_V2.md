# 界面风格与布局第二轮设计：让知识空间有生机

日期：2026-09-19。性质：对原视觉方案的设计补充，尚不代表生产界面已经实现或通过验收。

配套：[视觉、全局动效与星图专项设计](FRONTEND_VISUAL_MOTION_SPEC.md)、[知识体验整体改进方案](KNOWLEDGE_EXPERIENCE_REDESIGN.md)、[当前实现验收报告](REDESIGN_ACCEPTANCE_REVIEW_2026-09-19.md)。

## 1. 本轮目标与问题判断

用户进一步指出：现有页面虽然在动，但风格单调、缺乏生机，布局也需要重新考虑。本轮将视觉身份、信息编排、画布占比和动作节奏一起调整，允许替换整个应用壳与页面组件。

当前实现的主要视觉问题：

- 背景、卡片、输入框和详情都集中于相近的蓝黑色，明暗层次弱。
- 六页大量复用“固定宽侧栏＋大标题＋左右两张圆角卡”的构图，业务差异不够明确。
- 面板层层包围内容，大量边框和留白挤压真正的图形工作区。
- 动态主要来自背景轨道、虚线流动和淡入，材料、概念、证据的变化没有充分参与动作。
- 星图的生命感被误解为发光点和更多曲线；领域轮廓、概念层级、镜头、标签和内容展开尚未形成整体。

**新方向：温暖、轻盈、富有探索欲的知识空间。** “生长”用于表达材料形成结构、概念建立联系和理解逐步完成。概念、来源、数值和关系保持真实；图形生动但文字与操作稳定。

## 2. 美术方向

### 2.1 明亮阅读面与有深度的探索空间

推荐首先验证“暖纸与青绿”明亮版本，同时提供完整的“深林与暖光”暗色版本。默认主题仍可跟随用户偏好；是否改变产品初始主题应在两版原型比较后决定。

| 元素 | 明亮候选值 | 暗色候选值 | 使用目的 |
| --- | --- | --- | --- |
| 页面底色 | `#F7F5EF` | `#172420` | 避免所有层都落在蓝灰上 |
| 阅读表面 | `#FFFDF8` | `#25382F` | 稳定承载正文、证据和表单 |
| 主文字 | `#223C35` | `#EEF2E8` | 与底色形成明确对比 |
| 次文字 | `#65756B` | `#B4C3B8` | 真实可读的补充说明 |
| 主交互色 | `#267257` | `#A3D39A` | 导航、主要动作、当前路径 |
| 焦点色 | `#D96545` | `#F4A17E` | 当前概念、关键结论、局部响应 |
| 领域背景 | 柔和青绿、灰蓝、麦色 | 低亮度对应色域 | 以少量持久颜色区分领域 |

以上是设计候选值，须对实际组件测量对比度后锁定。不同领域同时配有文字与形态标记，不只依赖颜色。星图可以拥有更深的场景底色，但不会把整站阅读区都压暗。

### 2.2 形状、材质和字体

- 大块知识区域采用柔和、不规则的领域轮廓；正文和输入区用清晰规整的边界。
- 概念使用“标记＋名称＋按需展开的内容”，核心、普通、桥接概念有不同层次。近景允许转成有摘要的节点卡。
- 材料具有页片/书脊的视觉特征，来源有摘录与定位标记，避免所有对象看起来都是相同圆角矩形。
- 统一品牌标记可从“点与分支”出发，做少量状态变化；本轮不以吉祥物、卡通植物或随机粒子作为主视觉依赖。
- 页面标题、核心问题、阅读正文、注释建立明确大小层级。长中文标签完整展示，窄屏重排；不靠统一缩小字号解决拥挤。
- 材质只做低强度的纸面、柔和阴影与局部光场。正文背后不铺移动纹理或闪烁高光。

## 3. 应用壳与布局重构

### 3.1 全局导航

用紧凑导航与场景工具释放内容空间。桌面普通页面可使用顶部导航，主要页面入口保持同一位置；图形工作区可收起文字导航，只保留清晰的返回、当前位置与全局入口。图例、筛选、镜头控制归属于画布，不堆到全局页头。

窄屏保留“学习、材料、探索”主要分组，其余入口进入明确标注的菜单。菜单中的问答与练习依然可达，不把完整功能藏在无标签图标中。

全局壳、主题和概念身份一致，各页面根据任务采用不同构图。详情只在需要时出现；没有选择时不预占一整列空卡片。

### 3.2 六页布局

| 页面 | 新布局 | 主要变化与动作 |
| --- | --- | --- |
| 工作台 | 编辑式非对称版面：当前学习问题＋可操作知识片段；下方为继续学习和近期材料 | 用有意义的知识内容承担主视觉；选择材料时，邻域与问题同步变化，去掉无业务意义的大块宣言卡 |
| 材料与生成 | 桌面并列“来源/阅读”和“结构形成”；目标工具收进局部工具条 | 用户能对照原文与结果；处理完成后预览扩展为知识脉络，来源留在可展开抽屉中 |
| 知识脉络 | 全宽主线画布，顶部简洁的问题/结论；原文和证据按需展开 | 画布优先；主线、关系、大纲、原文围绕同一节点切换；流程、因果、对比采用不同排列 |
| 星图 | 以画布为主体的独立探索空间；浮动领域导航；选中后才显示详情 | 不再嵌在大卡片里的小窗口；先见清晰领域，再进入局部概念，详情打开时保持焦点可见 |
| 知识问答 | 中央连续对话与论证；底部输入；右侧按需展开证据与局部关系 | 提问、回答、证据形成阅读顺序；点击概念后同一对象延伸到图，不保留半屏空白介绍区 |
| 理解练习 | 单一清晰的答题舞台；题目、上下文和作答优先；反馈沿原位置展开 | 解释、比较、关系重建、情境应用各有表现；自评保存后出现下一步和网络状态变化 |

桌面图形工作区优先把约 70%–85% 的有效宽度交给图；此比例是原型起点，不是所有分辨率的硬约束。详情抽屉建议 300–360px；窄屏改为下方阅读区，不能盖住所选概念。

## 4. 让界面有生命感的动作语言

### 4.1 不同状态有不同节奏

| 时刻 | 动作 | 内容约束 |
| --- | --- | --- |
| 等待用户探索 | 场景轮廓缓慢呼吸，少量光场轻移 | 节点坐标、标签与命中区域稳定；阅读面不动 |
| 悬停/键盘聚焦 | 轮廓轻微舒展，关联入口显现 | 控件位置不跳动；触摸也能取得同样信息 |
| 选择概念 | 选中标记贴合概念，邻域出现，非相关层淡退 | 来源和真实边随选择更新，不能只改变颜色 |
| 打开材料 | 页片展开为阅读区，概念线索与摘录对应 | 材料与概念是来源关系，不能冒充同一对象变形 |
| 生成完成 | 主要结论先进入，主线接着展开，再给次级关系 | 只对已生成/校验的结构播放，不伪造处理中进度 |
| 切换总览/局部 | 领域轮廓变形，聚合线拆成真实边，标签接力 | 相机与布局连续；同一概念身份不变 |
| 自评保存成功 | 对应概念状态环变化，下一步操作出现 | 动效必须等服务端写入确认，不能替代真实复习记录 |

局部反馈约 120–220ms，面板展开约 250–450ms，镜头与领域展开约 450–800ms，均为待原型验证的范围。环境变化按秒计，低幅度、稀疏分布。新操作能随时接管；动画不锁住阅读或输入。

完整模式提供环境与结构动作；轻量模式保留短程状态过渡；静态模式停止环境、路径和镜头运动。静态不能仅隐藏背景，却继续执行 SVG/Pixi 循环。后台暂停、动态减少动画偏好和刷新持久化沿用原验收要求。

### 4.2 全站共用的变化规则

同一概念在列表里可以是标记，在主线里可以是节点，在星图里可以是星体。跨场景时保留稳定 ID、名称、领域色和选中状态，过渡路径明确。页面布局变化需要服务于当前对象：详情展开时画布让位，关闭时恢复，不整页重建。

实现上继续使用已有 React/Motion/SVG/Pixi 路线，但重建布局和状态层。允许推翻现有 App.tsx 的页面组织和单一 panel 样式，不要求继续兼容不适合新设计的组件。渲染器应复用，不能每次选择都销毁重建。

## 5. 星图的第二轮美术要求

仍严格执行原方案 L0–L6；本轮补充以下表现细节：

1. 总览以“领域的空间分布＋聚合联系”为主，保留空隙与清晰轮廓，不一次画出全部概念边。
2. 领域展开时，轮廓从总览形状平滑过渡到局部集合；概念沿稳定结构显现，不每次随机散开。
3. 核心概念、桥接概念和普通概念可一眼区分；显示规则与数据对应，不把未复习节点画成低价值节点。
4. 关系线有清楚的方向、类型和状态；流动只用于适合表达方向的选定路径，不能让全部曲线一直流动。
5. 焦点标签、邻居名称、关系标签有优先级、避让和边界约束。概念动效不带着文字漂移。
6. 证据通过清楚的选边/来源入口展开；背景光场不会截获点击，装饰点不会冒充知识节点。

## 6. 案例借鉴与预览范围

2026-09-19 重新查阅了 [House of Yellow 作者案例](https://tympanus.net/codrops/2026/09/16/house-of-yellow/)。案例把排版、SVG 形态、导航和内容变化一起设计为动态身份。本项目借鉴这种整体方法，将变化绑定到概念、来源与学习动作；具体色彩、布局和知识形态为本项目的设计提案。案例展示不等于代码可自由复制，也不作为本项目性能证明。

本轮会话中的交互预览覆盖工作台/星图两种布局、概念选择、说明更新、关系继续探索、暂停动效及明暗方向切换。所用监督学习内容明确标为示例；连线仅用于展示构图和交互，不作为正式带证据的知识关系数据。该预览用于讨论风格和布局，不替代生产实现、真实数据联调或四条完整分镜验收。

## 7. 实施与验收补充

- 先把工作台、单篇脉络、星图做成同一条真实内容链路，确定品牌、比例和动作节奏；再迁移问答、材料和练习，避免各页独立美化后无法衔接。
- 审查报告 F01–F12 与视觉重构一起排期。优先修正数据/持久化契约，再接真实关系动画；空白画布、假掌握度和失真关系不允许被新视觉遮掩。
- 关闭动画后仍需看出层次与风格；开启动画后，用户能辨认“什么变化了、为何变化、下一步是什么”。
- 验收首页与问答、练习、星图时，应具有明确不同的空间组织，同时保持同一品牌和操作语言。
- 桌面 1440×900、1280×800，移动端 390px/320px 下检查中文标签、抽屉、导航、触摸目标与正文行长。
- 旧方案的内容质量、真实来源、七层星图、四条分镜、无障碍与性能标准继续有效。本补充提升美术与布局目标，不缩减这些要求。
